Вводный практический курс по основам Python. Проект состоит из 10 алгоритмических задач, охватывающих ключевые концепции языка — от простых вычислений до работы с данными и динамическим программированием.

Технологии и инструменты:

Python 3
PyCharm (IDE)
Виртуальное окружение (venv)
JSON (работа с данными в задании про фильмы)
stdin/stdout (ввод-вывод через консоль)
Git (ветки develop/master, репозиторий)

Чему научился:

Базовые типы данных: числа, строки, булевы значения
Составные структуры данных: списки, кортежи, словари, множества
Управляющие конструкции: условия (if/elif/else), циклы (for, while)
Функции и рекурсия
Обработка исключений (try/except/finally)
Работа с файлами
Объектно-ориентированное программирование (классы, наследование, полиморфизм)
Алгоритмическое мышление: динамическое программирование (задача про робота), сортировка, поиск, работа с многочленами
Работа с JSON-данными (слияние списков фильмов)
Организация кода в отдельные модули и проекты
